# Thư mục âm nhạc (Background Music)

Bạn có thể thêm file bài hát yêu thích của bạn gái vào thư mục này:
- Đặt tên file là: `birthday.mp3`
- Đường dẫn: `public/music/birthday.mp3`

Khi file `birthday.mp3` được đưa vào, website sẽ tự động phát bài hát này.
Nếu chưa có file, website vẫn hoạt động hoàn hảo và phát giai điệu hộp nhạc lãng mạn tích hợp sẵn (Web Audio API) mà không gặp bất kỳ lỗi nào!
